# Learn Malayalam

**Learn Malayalam — the way Kerala actually talks.**

Interactive web app that teaches conversational Malayalam ("Manglish") to English speakers. Full plan and research live in [`planning/`](planning/PLAN.md).

## Development

```bash
npm install
npm run dev     # dev server
npm run build   # production build
```

Stack: Next.js (App Router) + TypeScript + Tailwind CSS v4, mobile-first.
