# Learn Malayalam

Learn Malayalam — the way Kerala actually talks.

Interactive web app that teaches conversational Malayalam ("Manglish") to English speakers: the casual, English-mixed register spoken in Kerala and heard in modern Malayalam movies.

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Full product plan, pedagogy, and research live in `planning/` — start with `planning/PLAN.md`.
